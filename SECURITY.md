# Security policy

## Supported versions

Security fixes are applied to the latest revision of `main`. Release tags are
supported only when a maintainer explicitly identifies them as current.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security** tab and select **Report a vulnerability** to
open a private report with the maintainers:

https://github.com/runtrue/github-actions-frontend/security/advisories/new

Include the affected revision, a concise impact statement, reproduction steps,
and any suggested mitigation. Do not include production credentials, private
customer data, or exploit material beyond what the maintainers need to
reproduce the issue.

Maintainers will acknowledge a report through the private advisory and keep
coordination there until a fix and disclosure plan are ready.
